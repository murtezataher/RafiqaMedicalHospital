# Hospital Management & Medical Center Website

A frontend-focused web application designed for a hospital or medical center to showcase departments, equipment, and basic facility management (such as room/bed availability).

## 🚀 Features
* **Department Pages:** Dedicated sections for General Surgery, Gynecology, and Pediatrics.
* **Facility Management:** Information and tracking pages for hospital equipment and bed/room availability.
* **Interactive Frontend:** Built with custom JavaScript to enhance user navigation and interface interactions.
